## Findings

### ENT-001: Two daily-count oracles, plus hand-copied headlines, already disagree

- **Priority:** P1
- **Dimensions:** Redundancy / sources of truth; Correctness / verification
- **Status:** observed fact
- **Evidence:**
  - Latest week caption: `reports/weekly-report-2026-08-16.md` line 159 — `Mon 08-10 3, Tue 08-11 1, … Sat 08-15 4, Sun 08-16 6`.
  - Matching SVG bar labels (non-zero comments): `reports/daily-activity-2026-08-16.svg` lines 111/223/540/670 (Mon 10 … Sun 16) and 1025/1052/1092/1125 (`4`, `3`, `5`, `7`).
  - Cache: `data/daily-repos.yaml` lines 206–210 — `2026-08-10: 4`, `2026-08-11: 3`, then zeros through `2026-08-14`; **08-15 and 08-16 absent**.
  - Dual generators: `docs/guide.md` lines 246–251 (`daily-chart.py` from `gather.sh`) vs lines 428–436 (`timeline-chart.py --weekly-dir` overwrites the same filenames). Producer implementations: `gather.sh` daily loop uses default branch, `--no-merges`, and `to_local_midnight`; `timeline-chart.py` `get_commit_dates` uses `--all` and bare `f"--since={since}"`.
  - README packed-cell `ℂ` values sum to **7066** (30 rows); At a Glance and Totals print `~7,068` (`README.md` lines 11 and 298).
- **Mechanism:** the same quantity (active repos per day; series commit total) is produced by more than one procedure and then copied by hand. The two chart producers do not share a git-log contract (landed vs `--all`, merges, timestamp expansion). The later `timeline-chart.py --weekly-dir` pass can silently replace the SVG that the weekly caption was written from. Headline totals have no sum check.
- **Blast radius:** every README timeline embed, every weekly Daily Activity figure, and the series commit total used in At a Glance / Journey. Readers and later `/progress-report` runs treat disagreeing numbers as ground truth.
- **Counterevidence checked:** the 2-day cache lag (`timeline-chart.py` writes only dates ≤ today−2) **explains missing 08-15/16 in the YAML** when the report was committed on 2026-08-16; it does **not** explain Mon/Tue 4 vs 3 and 3 vs 1, nor SVG 4/3/5/7 vs caption 3/1/4/6. Dual-home stubs do not affect these counts. `~` on 7,068 does not hide a mechanical 7066 vs 7068 split between the table and its totals row.
- **Smallest coherent remediation:** pick **one** daily-count function (prefer `gather.sh`'s midnight, default-branch, `--no-merges` walk). Have `timeline-chart.py` consume that series (or the YAML that `gather.sh` writes) instead of scanning git itself. Generate each weekly SVG once. Add a check that the week's caption tuple equals the SVG bar tuple equals the cache slice, and that README packed-cell `ℂ` sums to the Totals row.
- **Verification:** a fixture week whose gather output, cache YAML, SVG comments, and caption must be identical; a unit that fails if `sum(ℂ)` ≠ Totals.
- **Ratchet candidate:** command evidence `python3 -c '…assert caption == cache == svg…'` or a small script invoked from hygiene once declared; until then, a `file:` check is too weak because the files exist while disagreeing.
