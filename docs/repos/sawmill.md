# [marcelocantos/sawmill](https://github.com/marcelocantos/sawmill)

An open-source Go MCP server for structural code transformation — it teaches AI coding agents a project's own patterns, conventions and equivalences, backed by a lazy AST index over git history and an eighteen-language adapter matrix.

## The journey

sawmill entered the series mid-flight and immediately reinvented itself. Originally named **Canopy** and written in Rust, it was **rewritten to Go and open-sourced in a single 91-commit week** — Apache 2.0, a 271-line agents guide, a 458-line `STABILITY.md` cataloguing the public interaction surface, CI and release workflows — with the Rust codebase deleted once the port completed. The rewrite brought a daemon architecture (`sawmill` as stdio MCP proxy, `sawmill serve` as persistent daemon) whose handshake validates a **hash of the proxy's own binary** and restarts the daemon on mismatch, eliminating an entire class of stale-daemon debugging. In the same pass all state moved to `~/.sawmill/`, keyed by project path, so the server leaves zero footprint in the repositories it analyses.

The next phase built the knowledge layer on top of a **semantic git index**: tree-sitter parse trees stored by blob SHA in a normalised SQLite schema, walked first-parent and parsed lazily with dedup across commits. That index pays for three tools that ordinary git cannot serve. `git_blame_symbol` reports four commits per function — `introduced`, `last_modified`, `body_last_modified`, `signature_last_changed` — on the reasoning that signature changes have different migration consequences from body changes. `git_semantic_bisect` binary-searches ancestry for the commit where a structural predicate flipped without running any code, parsing only O(log N) commits. `semantic_diff` and `api_changelog` detect symbol moves across files, renames that preserve AST structure, and signature changes. Alongside them the **pattern-equivalence pillar** taught sawmill rewrite pairs and computed their transitive closure on demand via union-find, propagating a class's unanimous preferred pattern and neutralising contradictions rather than arbitrating them; and a **diagnostic-driven auto-fix loop** matched structured LSP diagnostics to taught fixes, terminating on clean/stuck/iteration-limit with cycle detection over `(file, code, message)` signatures so competing fixes cannot ping-pong. The runtime also swapped cgo tree-sitter bindings for pure Go, closing the C-compiler footgun. Releases v0.7.0 through v0.11.0 carried this.

Three focused releases followed. v0.12.0 shipped an **AST-aware three-way merge** that aligns base/ours/theirs by `(container, kind, name)` and applies a structural commute table, falling back to diff3 only for genuine `Modified + Modified` on the same declaration — turned on per repository through `.gitattributes` and a `merge.driver` entry, so parallel method additions and format-versus-logic edits stop producing conflict markers. v0.13.0 added **three-tier scope classification** after a Unity project's sawmill store reached 6.3 GB, 99.8% of it build artefacts: owned code gets full call graphs, library code gets public API only, build output gets nothing, with the insight that "ignored" and "library" are different things and conflating them costs the dependency context refactoring depends on. v0.14-era work added `find_by_concept`, ranking symbols by concept-alias hits over per-symbol evidence token bags built during indexing, verified against hand-curated ground truth at recall 1.00 and precision@5 of 1.00/1.00/0.80.

The final arc widened both retrieval and coverage. v0.16.0's discovery tier layered FTS5 lexical search, a reference graph with PageRank, and vector embeddings fused by Reciprocal Rank Fusion, with `find_by_concept` rebound to syntax nodes so concepts survive reformatting; the same week's [Fable-5 audit](../../reports/weekly-report-2026-07-05.md) surfaced two criticals and eight highs, data-loss-heavy — a `rename_file` root escape and an empty-file-undo deletion among them — all fixed in place. v0.17.0 then took the adapter matrix to **eighteen languages** and, crucially, drove parse → `find_symbol` → rename → apply → `add_field` through the MCP handler for every one of them **with no skip hatch**; writing that matrix immediately found a real Ruby bug. The standing principle: support that is not exercised end-to-end on disk is not support.

A 22 August entropy-follow-up squash replaced the tree with a one-line `f.py` (+1/−54,789). It sat that way until a revert on 31 August (outside the reporting window that recorded the wipe). The product survived; the incident is why an entropy squash is not a licence to replace a tree.

## Standouts

- **An eighteen-language matrix with no skip hatch** — `TestLanguageMatrixSmoke` drives parse → `find_symbol` → rename → apply → `add_field` through the MCP handler for every supported language with no escape for the awkward ones, and writing it immediately found a real Ruby bug. The standing principle: support that is not exercised end-to-end on disk is not support. ([2026-07-19](../../reports/weekly-report-2026-07-19.md))
- **A merge driver that understands declarations** — v0.12.0 aligns base/ours/theirs by `(container, kind, name)` and applies a structural commute table, dropping to diff3 only for a genuine `Modified + Modified` on the same declaration. Parallel method additions and format-versus-logic edits stop producing conflict markers, turned on per repository through `.gitattributes`. ([2026-05-03](../../reports/weekly-report-2026-05-03.md))
- **The proxy validates a hash of its own binary** — the daemon handshake compares binary hashes and restarts a version-skewed daemon automatically, eliminating an entire class of stale-daemon debugging; all state lives in `~/.sawmill/` keyed by project path, so a server analysing a repository leaves nothing inside it. ([2026-04-05](../../reports/weekly-report-2026-04-05.md))
- **A file-mutation tool that could escape its own root** — the Fable-5 audit weighted data-loss findings heavily and was right to: `rename_file` with `to="../../.zshrc"` overwrote arbitrary files with no recoverable backup, and undoing an edit to an originally-empty file *deleted* it through an empty-blob sentinel overload. Both fixed in place, root-contained and undo-safe. ([2026-07-05](../../reports/weekly-report-2026-07-05.md))
- **Tens of minutes of nothing before indexing even started** — v0.13.0's first `scope.New` used go-git's `ReadPatterns`, which recursively descends the entire tree collecting every nested `.gitignore`; on a Unity-sized project that blocked `model.Load` for tens of minutes, the exact opposite of the size problem the release shipped to fix. Now only the top-level `.gitignore` and `.git/info/exclude` are read, with a 1,000-directory regression test asserting sub-500 ms. ([2026-05-10](../../reports/weekly-report-2026-05-10.md))
