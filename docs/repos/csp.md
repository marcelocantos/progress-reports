# [marcelocantos/csp](https://github.com/marcelocantos/csp)

csp is a C++ CSP microthreading library: cooperative "imps" over an M:N work-stealing scheduler, typed synchronous and buffered channels with `alt`/`prialt` multiplexing, a single reactor abstraction over kqueue/epoll/Windows thread pool, and protocol stacks reaching HTTP/2 and QUIC. It ships as source, per-protocol amalgamated drop-ins and prebuilt libraries, backed by a large TLA+ model suite and an engineering-papers series that has reached #35.

## The journey

csp began as an extraction. In mid-February the concurrency module inside [squz/bricabrac](https://github.com/squz/bricabrac) was lifted into a standalone repository, the `brac` namespace renamed to `csp`, and the headers restructured under `include/csp/` — then immediately expanded with [Boost.Context](https://www.boost.org/doc/libs/release/libs/context/) microthreads, stream combinators, timer primitives implemented as channels (`sleep`, `after`, `tick`, so timeouts compose with `alt` rather than needing a separate timer API), a GMP-model M:N scheduler with work stealing, full ASan/UBSan/TSan targets with fibre annotations, and nanobench baselines. The same week bricabrac's own concurrency module was deleted in favour of the new library, a −5,556-line replacement.

The following week was the largest single effort of the entire series to that point: **133 commits taking csp from a bare extraction to a production platform**. It landed 100+ stream combinators in `csp::part`, channel topology surgery (`swap`, `fuse`, `splice`, `tap` — runtime rewiring of live channel connections, with `tap` auto-fusing the original link back on destruction), a supervision and cancellation framework with cancel-aware TLS routed through the reactor via custom mbedTLS BIO callbacks, a kqueue I/O reactor, `csp::dynamic<T>` dynamic-scoped variables backed by a persistent [HAMT](https://en.wikipedia.org/wiki/Hash_array_mapped_trie), demand-paged 1 MB mmap stacks with guard pages and mid-flight `maybe_shrink()` reclamation, an ARM64 stack-depth analyser, a C++23 migration, 400+ tests, and documentation comprising an 11-chapter guide, 50+ combinator reference pages with SVG diagrams compiled from an ASCII-art DSL, and the first six engineering papers. Nine-plus TLA+ models, exhaustively checked by TLC, covered the suspension TOCTOU race, work stealing, channel lifecycle, worker parking and alt-state CAS.

Portability and correctness dominated the next month. A five-phase Windows port added `VirtualAlloc` stack pools, a `CreateThreadpoolTimer` reactor with mutex-serialised cancel-vs-callback resolution, `WSAEventSelect` socket I/O, CI, and console control events via a loopback TCP socket-pair mirroring the Unix self-pipe trick; a Linux epoll backend joined it, giving three reactor implementations behind one `fd_event` abstraction. The hardest bug of the phase was ARM64 thread-local corruption: the compiler cached `TPIDR_EL0` in a callee-saved register that fcontext restores across a switch, so an imp resuming on a different OS thread read another thread's TLS. Formal verification matured into **paired fix and bug specifications** — the bug variant of the scheduler-termination race violates its safety property in exactly seven steps, making the spec regression-proof documentation. March closed with a sweeping M:N-only migration (663/663 tests, no 1:1 fallback) plus `quiescence_scope` and a `fake_clock` quiescence hook, which together make an inherently non-deterministic scheduler deterministic under test.

From April the library grew outward into I/O and protocols: `fd_t` and file I/O, an HTTP/1.1 server wrapping [llhttp](https://llhttp.org/), an HTTP/1.1 client, an HTTP/2 server over nghttp2 with ALPN, in-band channel exception delivery so a sender-side throw surfaces on `recv` instead of vanishing, per-worker wake replacing the single ready-queue condvar (a 4-6× reduction in cross-core futex traffic on a 16-core M4 Max), and **QUIC on [ngtcp2](https://github.com/ngtcp2/ngtcp2) with PicoTLS minicrypto** in v0.13.0. Distribution proved harder than the protocols. The monolithic 117 K-line `dist/csp_net.cpp` generated but would not compile — ~623 hard errors, because `extern "C"` controls linkage, not parsing, and Clang has no pragma to compile part of a `.cpp` as C99. That approach was retired for **per-protocol drop-in translation units governed by five DCE rules**, letting the linker select protocols, followed later by a prebuilt-library release pipeline so consumers need not rebuild the world.

Mid-year work inverted the I/O model and hardened the runtime. A pull-based `io::source` was threaded through `tls::stream`, `http::fetch` and `http::serve`, and then the push-based `net::connection.input` was **removed outright** rather than deprecated — back-pressure falls out of one abstraction instead of being reconciled between two. The fleet-wide Fable-5 deep audit, whose two-lens methodology defaults every finding to "refuted" until both a reachability lens and an invariant-validity lens confirm it, filed csp targets that fixed a stack-slot size taken from a checkpoint sample rather than a sound bound (a silent cross-microthread corruption risk on arm64 with no guard page) and an ASan over-read, alongside a CI hang watchdog that self-backtraces.

The final phase is performance, done measurement-first. A bench showed the wrong *shape*: a serial two-imp rendezvous got **16× slower** from 2 to 16 processors (321 ns → 5,081 ns), root-caused to unconditional `global_mu` on every context switch and wake. The hot-path overhaul flattened rendezvous to **~146 ns across processor counts** and gave the buffered channel its own ring, with `OptimisticAlt`, `BufferedChanRing`, `ParkGate`, `DrainSuspended` and `PlacementClaim` models plus papers 33-34. A follow-up scheduler-thrash fix — a deferred-wake path that still hard-coded the old global-queue push, steals bouncing through the global queue, and idle workers taking the global mutex merely to test emptiness — bought ~3× on multi-writer `alt/8ch` (3.2 µs → 1.07 µs). Paper 35 then ranked every non-channel surface and concluded, defensibly, that there were no large actionable opportunities, filing zero follow-up targets. Windows CI was split into a cheap non-required cloud smoke and an authoritative local ARM64 VM gate that reads pass/fail from an in-band stdout marker rather than trusting ssh to propagate an exit code. The whole-suite oracle stands at 767 cases and 26,522 assertions.

- **Channel rendezvous flattened to ~146 ns** — a measured 16× negative-scaling curve root-caused to `global_mu` on every switch and wake, fixed with a channel-owned buffered ring and five new formal models. ([2026-07-19](../../reports/weekly-report-2026-07-19.md))
- **Scheduler thrash worth ~3× and a trusted Windows gate** — multi-writer `alt/8ch` from 3.2 µs to 1.07 µs, plus a two-tier Windows CI whose authoritative half is a local ARM64 VM keyed on an in-band marker. ([2026-07-26](../../reports/weekly-report-2026-07-26.md))
- **Stacks sized from machine code** — an ARM64 walker returning maximum SP displacement with an honest `is_exact` flag, indirect branches resolved through live data, composed with a measured shell constant under an audit gate (v0.29.0). ([2026-08-02](../../reports/weekly-report-2026-08-02.md))

## Standouts

- **Thread-locals that belonged to another thread** — on ARM64 the compiler cached the thread pointer `TPIDR_EL0` in a callee-saved register and fcontext restored it across a context switch, so an imp resuming on a different OS thread silently read another thread's TLS; fixed by routing TLS access through cross-TU calls that force a re-read on every access. ([2026-03-01](../../reports/weekly-report-2026-03-01.md))
- **Paired fix and bug specifications** — every verified race ships two TLA+ specs, and the bug variant of the scheduler-termination race violates its safety property in exactly seven steps, turning the model into regression-proof documentation rather than a one-off proof. ([2026-03-01](../../reports/weekly-report-2026-03-01.md))
- **QUIC shipped; the amalgamation didn't** — `csp::quic::listen`/`dial` landed on ngtcp2 with PicoTLS minicrypto, while the 117 K-line monolithic `csp_net.cpp` died on ~623 errors after `extern "C"` proved to control linkage, not parsing, with no Clang pragma to compile part of a `.cpp` as C99. ([2026-05-03](../../reports/weekly-report-2026-05-03.md))
- **A channel that got slower with more processors** — a serial two-imp rendezvous measured 16× *worse* from 2 to 16 processors (321 ns → 5,081 ns) because `drain_suspended` and `Imp::schedule` took `global_mu` on every switch and wake; the hot-path overhaul flattened it to ~146 ns across all processor counts. ([2026-07-19](../../reports/weekly-report-2026-07-19.md))
- **A fast path with a hole in it** — wake-to-local was already in, but the *deferred*-wake path taken on every close-race rendezvous still hard-coded the old global-queue push, re-entering the park/steal storm it was meant to end; the fix turned on `placed_` already serialising against `schedule()`, which let an entire dual-lock dance be deleted and bought ~3× on multi-writer `alt/8ch`. ([2026-07-26](../../reports/weekly-report-2026-07-26.md))
