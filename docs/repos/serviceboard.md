## The journey

Loopback-only local dashboard for Supervisor and Homebrew services: status, recent logs, start/stop/restart, search keyboard navigation, focused live updates. Refuses non-loopback Host headers; per-run token + Origin for controls.

Born week ending 2026-09-27 (10 commits landed). The week ending 2026-10-11 replaced personal paths in the Supervisor sample config.

The week ending 2026-10-18 cut **v0.1.0**, the first tag: page-height panels, eased Page Up/Down that keeps the selection, a keyboard journey test, an agent guide, and a root `NOTICE`.
